# iPad 专用分支与多直播实现

目标：在独立分支提供与现有应用共存的 iPad 版本，支持 1–4 路直播，不修改通用 dev 分支。

架构：独立多直播页面统一管理原生播放器和唯一音源；每路仅管理详情、清晰度与视频资源，不复用单直播间全局历史计时。宽窗侧栏、窄窗抽屉；聚焦只改变布局。使用 Flutter/media_kit，按现有平台接口解析直播。

- [x] 建立 codex/ipad-multiview 分支。
- [x] iPad 专用 Bundle ID、显示名、设备家族与仅 iPad Actions。
- [x] 多直播会话：容量、去重、音源、代次检查、顺序释放、前后台暂停副屏。
- [x] 多直播 UI：网格、侧栏、手工房间 ID、单路聚焦、质量/重试/关闭。
- [x] 首页和关注菜单入口，按实际窗口宽高选择导航布局。
- [x] 布局、容量/音源、原生命令顺序回归与交叉审查；多直播模块静态分析无问题。
- [x] plist、Bundle ID/设备家族、YAML 以及仅 iPad job 启用的配置断言通过。
- [ ] iPad 远程构建完成及实机安装验证（推送后跟踪 Actions）。

实现边界：暂不提供多路弹幕或多路观看统计；独立应用首次无旧版数据，可通过导入备份迁移。未签名 IPA 安装时必须使用不同于原版的 Bundle ID。iPad 真机的多解码器性能、后台音频和系统多任务需要实测。
