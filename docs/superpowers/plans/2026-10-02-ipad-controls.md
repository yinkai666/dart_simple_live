# iPad 多直播交互完善

范围：多音源及每路音量、头像、明确设置与移除操作、文字弹幕、放大后的亮度/音量手势。继续保持独立 iPad 分支与安装标识。

设计：音源由单选改为独立集合并保留独听；每路弹幕持有自己的连接和有界队列；视频状态变化与弹幕批次分别通知。多格保留滚动，放大单路才拦截竖向调节手势。亮度由页面统一持有，跨页面串行写入，旧页面不能重置新页面亮度。

菜单调查：material_ui 1.1.1 定义独立 MaterialLocalizations 类型，而多直播页使用 Flutter Material；主应用只注册前者。根 Navigator 与多直播局部均补齐 Flutter delegates，避免弹窗 route chrome 找不到类型。三点菜单改为「设置」，「×」直接移除。

验证：多音源/删除/音量边界、弹幕缓冲、手势方向与队列关闭、跨页面亮度所有权使用独立 Dart 检查；本地化页面与 root Navigator 弹层、左右手势及多格滚动使用 Flutter widget 测试。新模块执行定向静态分析，CI 在打包前运行同样检查。iPad 实际网络、声音混合、亮度通道和弹幕性能仍需安装测试。
