# 普通直播卡顿与断流恢复

用户反馈：斗鱼普通单直播，iPadOS 16.6.1，播放时卡顿逐渐增加直至断流；手动刷新可恢复；时长不固定，短时间也会发生。不能将此认定为固定五分钟地址到期。

已确认代码问题：普通 iOS 播放关闭前向缓存；error/completed 恢复只重试旧 URL，线路耗尽后不重新请求播放地址，并可能把网络失败当作主播下播。

实现范围：

- iOS 开启约 3 秒前向缓存，解复用缓冲上限 16 MiB，不保留历史回看缓存。此上限不包含视频解码器及纹理内存。用户显式双重缓存选项仍保留。
- 单直播在错误、流结束或前台持续缓冲时合并自动恢复，重新获取当前清晰度的新地址；保留最高默认清晰度，不自动降画质。
- 自动恢复有请求超时、尝试上限及间隔；新地址返回不代表成功，需实际持续播放进展才重置预算。
- 手动操作、换台和关闭使旧恢复任务失效；停止重复请求，最终明确提示手动刷新，不把网络失败直接标记成下播。

验收：恢复策略的重复事件、预算、稳定播放、长缓冲/暂停/后台条件及代次失效检查；原有切台回归；构建后需用实际斗鱼房间验证网络与播放器表现。
